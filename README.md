# 食材解凍效期管理與每日記錄 (Food Thaw & Expiry Tracker)

專為廚房料理與食材保鮮設計的輕量解凍推算與每日記錄工具。遵循「**解凍 1 天、可使用 3 天**」的效期邏輯，採用溫暖清新的 **柔和長春花藍 (`#8894FF`)** 與 **暖杏蜜桃色 (`#FFDCB4`)** 現代美感配色，畫面純粹俐落。

---

## 🌟 核心功能說明

### 1. 效期推算查詢 (Tabs 1)
- **以現在日期為基準推算**：預設自動以今天日期為解凍起算點，可自由切換指定日期。
- **純粹食材選擇**：快速搜尋或透過肉類標籤（🐷 豬肉、🐔 雞肉、🥩 牛肉）點選食材。
- **「解1用3」標準推算**：
  - 🧊 **解凍日期**：例如 `11/15` 開始冷藏解凍。
  - 🍳 **可使用日**：例如 `11/16` 達到可烹調狀態（解凍 1 天）。
  - ⚠️ **過期日**：例如 `11/19` 過期（可使用 3 天，11/19 起過期）。
- **一鍵記入當日記錄**：點擊「記入 11/15 解凍記錄」，自動歸入每日解凍清單。

### 2. 每日解凍記錄 (Tabs 2)
- **依日期自動分組與整天刪除**：例如今天新增即會自動歸類在「**11/15 解凍項目**」群組底下，日期旁附有「**刪除**」按鈕，可一鍵清空該整天的所有解凍項目。
- **純粹清爽版面**：顯示「**食材品名**」與「**備註：解幾用幾**」，並輔以「**解凍日期**」與使用、過期效期對照（如 `11/15 解凍 ➔ 11/16 使用 ➔ 11/19 過期`）。
- **當前保鮮狀態**：自動比對今日日期顯示 `解凍中`、`可使用`、`已過期`。
- **頂部快速新增列**：可在同一頁面選擇日期與食材，快速把多種肉品一口氣加入當天的解凍記錄中。

### 3. 食材規則庫 (Tabs 3)
- **自由新增與移除食材**：可隨時新增自己的肉品，或刪除不要的項目。
- **純粹資訊**：已完全移除備註與繁瑣欄位，僅保留**食材品名**、**肉類標籤**、**解凍天數**與**可用天數**。
- **永久儲存**：資料儲存於瀏覽器 LocalStorage，重新整理或重啟瀏覽器依然完整保留。
